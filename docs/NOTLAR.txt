3. SİSTEM NASIL ÇALIŞIYOR
--------------------------------------------------------------------------------
  IMX219 kamera (CSI0, 1920x1080 @30) -> tiovxisp -> tiovxmultiscaler
     |-> 1280x720 RGB  -> Python (Norfair izleme + çizim)  -> H.264 -> RTP <RTP alıcısı>:5000
     |                                                      -> MJPEG web :8080
     |                                                      -> DSI panel (/dev/fb0)
     `-> 640x360 (letterbox ile 640x640) -> C7x: YOLOX-s WIDER FACE yüz modeli

  Model : /opt/model_zoo/ONR-OD-8420-yolox-s-lite-mmdet-widerface-640x640, sınıf "face"
          (kişi takibi için: TFL-OD-2020-ssdLite-mobDet-DSP-coco-320x320 + [person])
  Mod   : lock -> tek hedefe kilitlenir; hedef kaybolunca 1 s bekler, sonra
          dur-kalk tarama yapar (10° atla, 0.8 s dur, pan -60..+60).
  Servo : donanım PWM epwm1 (23010000.pwm), sysfs /sys/class/pwm/pwmchipN.
          pan = PWM kanal 0 (GPIO6), tilt = PWM kanal 1 (GPIO13).
  Servis: object-tracker.service (root) -> /home/gemstone/object-tracker-o1/start_tracking.sh
          açılışta otomatik başlar (enabled).

  EKRAN ARAYÜZÜ (panel_ui.py, sadece panelde; web/RTP'de yok):
    Yön okları (sağ alt)   : basılı tut -> kamera döner (30°/s), MANUEL mod
    OTO/MANUEL (sol alt)   : otomatik takibe dön
    ATES (altta kırmızı)   : servo geri tepme + VURULDU!/ISKA efekti, SKOR
    Efekt butonları (sağ)  : SADE / NISAN / GECE / TERMAL
    Bir yüze dokun         : kilidi o yüze geçir (diğer yüzler gri köşeli)
    Boşluğa dokun          : kilidi bırak, otomatik seçime dön

6. YAPILAN DEĞİŞİKLİKLER VE NEDENLERİ (kronolojik özet)
--------------------------------------------------------------------------------
  1) Donma / düşük FPS: udpsink, ulaşılamayan RTP alıcısında (ARP çözülemeyince)
     2-3 s bloklanıyor, appsrc block=True yüzünden tüm döngü duruyordu.
     -> udpsink önüne leaky queue (200 ms). 5.5 FPS -> 30 FPS (kişi modeli).
  2) Servo tahmin kutusunu kovalıyordu -> sadece o karede gerçekten tespit edilen
     (live) hedefte servo hareket eder, tahminde bekler.
  3) Açılış: servis After=multi-user.target'ı bekliyordu (-5 s kaldırıldı);
     sistem cv2'si 355 kütüphane (soğuk açılışta ~9 s) -> headless OpenCV
     /opt/tracker-pylibs. Soğuk açılışta ilk kare ~21 s -> ~16.5 s.
  4) SIGTERM ile durdurma TIOVX'i kilitledi -> KillSignal=SIGINT + exec.
  5) Arama modu eklendi (sonra dur-kalk yapıldı; sürekli dönüş bulanıklaştırıyordu).
  6) Kişi -> yüz modeli. Uygulama 16:9'u 640x640'a geriyordu, yüzler %44 dar,
     skor 0.3-0.6 -> letterbox (640x360 + gri dolgu), skor ~0.8.
  7) Kamera hareketi telafisi: Norfair'e servo açısından TranslationTransformation
     veriliyor; yoksa kamera dönüşü hedef hızı sanılıp kilit 1-2 s'de kopuyordu.
  8) Pan/tilt PWM kanalları ters bağlıydı -> değiştirildi, yönler logla doğrulandı.
     Sonuç: 50 s boyunca kopmasız kilit, dx/dy ~0'a yakınsıyor.
  9) Web görüntü (MJPEG), DSI panel çıkışı, dokunmatik, ekran butonları,
     efektler, ateş butonu eklendi.
 10) HUD'da ters kutu (x2<x1) cv2.ellipse'i patlatıp döngüyü öldürüyordu ->
     kutu normalize, HUD hatası kareyi atlar, döngü ölürse uygulama kapanıp
     systemd yeniden başlatır.

9. TUZAKLAR - MUTLAKA OKU
--------------------------------------------------------------------------------
  * Uygulamayı HER ZAMAN SIGINT (Ctrl+C / systemctl stop) ile durdur. SIGTERM/kill
    TIOVX'i kilitler: sonraki her açılışta "Unable to init TIOVX module" /
    "Error pulling tensor" / segfault döngüsü. Tek çare: kartı yeniden başlat.
  * `pkill -f <desen>` KULLANMA: SSH ile verilen komut satırının kendisini de
    eşleştirip oturumu öldürüyor (birkaç kez oldu).
  * SSH'de `echo <şifre> | sudo -S ... <<EOF` çalışmaz (heredoc, şifrenin stdin'ini
    ezer) -> betiği önce dosyaya yaz, sonra sudo ile çalıştır.
  * /boot eMMC'nin boot bölümü; kart SD'den açılıyor. uEnv.txt'yi
    /dev/mmcblk1p1'de düzenle (sudo mount /dev/mmcblk1p1 /mnt/sdboot).
  * Servo yönünü tahminle değiştirme. servo_debug: True yap, kilitliyken
    [SERVO] satırlarına bak: servo dönerken |dx| ve |dy| KÜÇÜLMELİ. Bir kez
    kullanıcı yorumuna ve faz korelasyonu ölçümüne güvenip yanlış çevrildi.
  * Ölçüm için servisi durdurunca web/panel görüntüsü de gider; bittiğinde
    servisi yeniden başlatmayı unutma.
  * journalctl'de Python stdout tamponlu; zaman damgaları gerçeği göstermeyebilir
    (flush=True olan satırlar hariç).
  * Kartta fdtoverlay/dtc yok; overlay birleştirme testini PC'de yap.
  * RTP hedefi (<RTP alıcısı>) kapalıyken bile artık tracker donmaz (leaky queue),
    ama o makineye görüntü gitmez; ping ile kontrol et.
